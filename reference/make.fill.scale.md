# Make heatmap colors for interaction plots

Make heatmap colors for interaction plots

## Usage

``` r
make.fill.scale(pal, Effect)
```

## Arguments

- pal:

  the string for the palette desired

- Effect:

  numeric for the effect estimate

## Value

a ggplot color palette
